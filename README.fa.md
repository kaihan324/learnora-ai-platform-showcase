# Learnora AI Platform — نسخه نمایشی عمومی

**Learnora** یک پلتفرم دستیار هوشمند آموزشی مبتنی بر Telegram است که قابلیت‌های گفت‌وگوی AI، جستجوی زنده وب، حافظه معنایی، RAG اسناد، پردازش صوت و تصویر، صف کارهای پس‌زمینه و مانیتورینگ Production را در یک سیستم یکپارچه جمع می‌کند.

> این Repository فقط برای **نمایش عمومی پروژه** است و عمداً شامل سورس Production، Secretها، IPهای داخلی، تنظیمات واقعی سرور، لاگ‌های خصوصی یا داده کاربران نیست.

## قابلیت‌های اصلی

- AI چند Provider با failover
- جستجوی زنده وب
- حافظه مکالمه + حافظه معنایی بلندمدت
- Hybrid RAG با lexical retrieval + pgvector + reranking
- پرسش و پاسخ از فایل
- Voice transcription و workflowهای آموزشی
- OCR و تحلیل تصویر
- Study Planner، Quiz، Flashcards، Summary و Translation
- Background Job پایدار روی PostgreSQL
- Health / Ready checks
- Prometheus + Grafana
- داشبورد عملیاتی `/ops`

## هدف این Repo

این Repository برای نمایش حرفه‌ای پروژه در GitHub، رزومه، LinkedIn و مصاحبه فنی ساخته شده است. سورس Production در Repository خصوصی جداگانه نگهداری می‌شود.
