# Learnora v4.1.0 — Public Showcase

Learnora v4.1.0 is the public showcase release of a production-oriented Telegram AI learning platform.

## Highlights

- Human-first Telegram UX
- Multi-provider AI routing with health-aware failover
- Live web intelligence for current questions
- Conversation context plus semantic long-term memory
- Hybrid document RAG with lexical retrieval, pgvector, candidate fusion, and reranking
- Voice transcription, OCR, vision, TTS, study-planning, quiz, and flashcard workflows
- PostgreSQL-backed durable background jobs
- Health/readiness endpoints and operational telemetry
- Prometheus + Grafana observability
